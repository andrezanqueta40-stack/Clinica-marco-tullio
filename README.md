# Clínica Veterinária Dr. Marco Tullio

Site da Clínica Veterinária Dr. Marco Tullio, em Poços de Caldas (MG).

## Publicar no GitHub Pages

1. Crie um repositório no GitHub e envie todos os arquivos desta pasta (`index.html` e a pasta `img`).
2. No repositório, abra **Settings → Pages**.
3. Em **Source**, escolha **Deploy from a branch**, selecione a branch `main` e a pasta `/ (root)`, e clique em **Save**.
4. Em alguns minutos o site fica disponível em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Onde editar

- **Número do WhatsApp e mensagens:** no final do `index.html`, nas variáveis `NUMERO` e `MSGS`.
- **Número para ligar:** procure por `tel:+5535999872977` no `index.html`.
- **Fotos:** substitua os arquivos da pasta `img` mantendo o mesmo nome.
- **Cores:** no início do `index.html`, nas variáveis `--mata`, `--folha`, `--broto` e `--nevoa`.
